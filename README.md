# Predictive Telemetry & Flash Reliability Analysis

An advanced machine learning application that analyzes telemetry data (wear levels, P/E cycles, temperature, and error rates) to predict SSD failures before they happen.

## 🚀 Features
* **Real-Time Monitoring**: Beautiful dark-themed analytics dashboard tracking drive health metrics.
* **Predictive AI**: Machine learning models evaluating data center flash reliability and risk levels.
* **Interactive UI**: Fully functional Flask web application complete with registration and sample dataset testing tools.

## 🛠️ Tech Stack
* **Backend**: Python, Flask, SQLite3
* **Data Science**: Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib
* **Frontend**: HTML5, CSS3, JavaScript

## 📦 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the folder:
   ```bash
   cd "SSD Failure"
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the app:
   ```bash
   python app.py
   ```
5. Open your browser and navigate to `http://127.0.0.1:5000`
